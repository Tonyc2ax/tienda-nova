# NOVA SHOP

Bienvenido a NOVA SHOP, una tienda virtual donde puedes explorar diferentes productos de tecnología, moda, accesorios y artículos para el hogar.

Nuestra tienda está diseñada para que encontrar lo que buscas sea sencillo y cómodo.

## Nuestros productos

Contamos con diferentes categorías:

- **Tecnología:** auriculares, teclados y accesorios.
- **Moda:** zapatillas y complementos.
- **Accesorios:** mochilas, relojes y otros artículos.
- **Hogar:** lámparas, tazas y productos de uso diario.

## Nuestra tienda

En NOVA SHOP puedes consultar los productos disponibles, ver sus precios y agregarlos al carrito de compras.

También puedes buscar productos por nombre, filtrar por categoría y organizar los resultados según tus preferencias.

La página se adapta a computadoras, tablets y celulares para facilitar su uso desde cualquier dispositivo.

## Cómo comprar

1. Explora nuestro catálogo.
2. Selecciona los productos que te interesen.
3. Agrégalos al carrito.
4. Revisa tu pedido y el subtotal.
5. Solicita información por WhatsApp, cuando esta opción esté disponible.

## Sobre NOVA SHOP

NOVA SHOP nace como un proyecto de tienda virtual pensado para ofrecer una forma sencilla de explorar y seleccionar productos en línea.

Actualmente es una versión de demostración, por lo que los productos y precios son de ejemplo y no se realizan pagos reales.
